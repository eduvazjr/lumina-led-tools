┌──────────────────────────────────────────────────────────────────────────────┐
│ INSTALAÇÃO                                                                   │
└──────────────────────────────────────────────────────────────────────────────┘

1️⃣  INSTALAR (se Django não estiver instalado)
    $ pip install django decouple dj-database-url

2️⃣  CRIAR MIGRATIONS
    $ python manage.py makemigrations contabilidade

3️⃣  APLICAR MIGRATIONS
    $ python manage.py migrate contabilidade

4️⃣  COLETAR ESTÁTICOS
    $ python manage.py collectstatic --noinput

5️⃣  INICIAR SERVIDOR
    $ python manage.py runserver 0.0.0.0:8000

6️⃣  ACESSAR SISTEMA
    🌐 Dashboard: http://localhost:8000/contabilidade/
    🔧 Admin:     http://localhost:8000/admin/

🚀 INSTALAÇÃO RÁPIDA
    $ python instalar_contabilidade.py

┌──────────────────────────────────────────────────────────────────────────────┐
│ EXEMPLO DE USO                                                               │
└──────────────────────────────────────────────────────────────────────────────┘

1. Acesse /contabilidade/
2. Clique "Novo Processo"
3. Preencha:
   • Número: PROC-2026-001
   • Cliente: Selecione da lista
   • Status: Entrada de Cliente
4. Salvar
5. Navegar pelos 5 módulos:
   → Entrada de Cliente (dados do contato inicial)
   → Legalização (CNPJ, alvarás)
   → DP (funcionários, folhas)
   → Fiscal (tributos, obrigações)
   → Contábil (lançamentos, DRE)
6. Sistema rastreia progresso automaticamente
7. Dashboard mostra alertas e pendências
