🎯 Como Começar

1
Instalação Inicial (Primeira Vez)

Na área de trabalho, dê duplo clique em:

💡 Instalar Led Gerencial

O script vai automaticamente:

  • Instalar Django e dependências
  • Criar 3 novos módulos gerenciais
  • Configurar banco de dados SQLite
  • Iniciar o servidor automaticamente

⏱️ Tempo estimado: 2-3 minutos

2
Aguarde a Instalação

Uma janela do PowerShell vai abrir mostrando o progresso:

📦 PASSO 1: Instalando Django e dependências...
✅ Django instalado com sucesso!

📋 PASSO 2: Criando migrations...
✅ Migrations criadas com sucesso!

🗄️ PASSO 3: Aplicando ao banco...
✅ Banco de dados atualizado!

🚀 INICIANDO SERVIDOR...

NÃO FECHE esta janela! O servidor está rodando.

3
Acessar o Sistema

Quando o servidor iniciar, clique no atalho:

🌐 Led Gerencial - Abrir

Ou abra manualmente no navegador: http://localhost:8000

Login: admin
Senha: admin123

⚠️ IMPORTANTE

Após a primeira instalação, para iniciar o Led Gerencial novamente, use o atalho 🚀 Led Gerencial - Iniciar (não precisa reinstalar).
