📤 Como Importar Planilhas

Guia completo para importar pagamentos a fornecedores no Led Gerencial v7.5

📊 Formatos Aceitos

  • CSV (.csv) - Delimitador: ponto-e-vírgula (;)
  • Excel (.xlsx ou .xls) - Formato moderno do Microsoft Excel

📋 Estrutura da Planilha

Coluna Descrição Exemplo Obrigatório
fornecedor_cnpj ou fornecedor_nome CNPJ ou nome do fornecedor (deve estar cadastrado) 12.345.678/0001-90
ou
ACME LTDA		 ✅ Sim
descricao Descrição do pagamento Compra de materiais ✅ Sim
valor Valor (use ponto como decimal) 1500.00 ✅ Sim
data_emissao Data de emissão (DD/MM/AAAA) 21/10/2026 ✅ Sim
data_vencimento Data de vencimento (DD/MM/AAAA) 30/10/2026 ✅ Sim
observacoes Observações adicionais Pedido 001 ❌ Não

🎯 Passo a Passo

1 Baixe o modelo

Use o botão "⬇️ Baixar Modelo CSV" no dashboard ou os links abaixo:

📄 Baixar Modelo CSV
2 Preencha seus dados

Abra o arquivo no Excel, LibreOffice ou editor de texto e preencha com seus pagamentos.

3 Certifique-se de que os fornecedores existem

Todos os fornecedores mencionados na planilha devem estar cadastrados em Cadastros → Fornecedores.

4 Importe no sistema
  • Acesse Gestão Avançada → Controle Gerencial
  • Clique em "📤 Importar Planilha"
  • Selecione seu arquivo
  • Clique em "🚀 Importar Agora"

✅ Exemplo CSV Válido

fornecedor_cnpj;descricao;valor;data_emissao;data_vencimento;observacoes
12.345.678/0001-90;Compra de materiais;1500.00;21/10/2026;30/10/2026;Pedido 001
98.765.432/0001-10;Serviços de manutenção;2300.50;21/10/2026;05/11/2026;Contrato 2026
ACME LTDA;Fornecimento de equipamentos;5000.00;20/10/2026;25/10/2026;Urgente
⚠️ IMPORTANTE:
  • Use ponto-e-vírgula (;) como separador no CSV
  • Valores numéricos usam ponto (.) como separador decimal
  • Datas sempre no formato DD/MM/AAAA
  • Não deixe linhas vazias entre os registros
  • A primeira linha (cabeçalho) será ignorada no Excel

🔧 Solução de Problemas

❌ Erro: "Fornecedor não encontrado"

Solução: Cadastre o fornecedor primeiro em Cadastros → Fornecedores

❌ Erro: "Formato de data inválido"

Solução: Use sempre DD/MM/AAAA (exemplo: 21/10/2026). No Excel, formate a célula como "Texto" antes de digitar.

❌ Erro: "Biblioteca openpyxl não instalada"

Solução: Execute no terminal: pip install openpyxl

✅ APÓS A IMPORTAÇÃO:
  • Uma mensagem de sucesso aparecerá mostrando quantos registros foram importados
  • Os KPIs do dashboard serão atualizados automaticamente
  • Um log completo da importação fica salvo no banco de dados
  • Erros são registrados linha por linha para fácil correção
